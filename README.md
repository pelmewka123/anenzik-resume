# ANENZIK — резюме-игра

Резюме Андрея Мищенко (Fullstack · GameDev) в виде 3D-карты в стиле MOBA.
Нажимаешь «Играть», камера ныряет в карту, и дальше резюме изучается от первого лица.

## Управление

| Действие | Как |
|---|---|
| Следующая / предыдущая точка | `→` / `←`, пробел или кнопки внизу справа |
| Полёт в любую точку | клик по миникарте |
| Осмотреться | зажать мышь и двигать |
| Способности | `Q` `W` `E` `R` |
| Ластхит | клик по вражескому крипу |
| Всё резюме одним экраном | `TAB` |
| Музыка | `M` |

## Что на карте

1. **Фонтан** — карточка героя
2. **Лавка** — навыки как предметы
3. **Башня знаний** — образование
4. **Башня опыта** — опыт
5. **Руна хобби** — увлечения
6. **Лес проектов** — проекты
7. **Логово Дедлайна** — бой с боссом
8. **Трон Безработицы** — финал и контакты

## Технологии

- HTML, CSS, JavaScript без сборщиков
- [Three.js](https://threejs.org/) r149 — 3D (лежит локально в `lib/`)
- Web Audio API — музыка и звуки генерируются кодом, без аудиофайлов
- Вся графика процедурная: карта, деревья, башни и босс собраны из примитивов

## Структура

```
index.html      разметка, HUD
css/style.css   стили интерфейса
js/data.js      ВСЕ тексты резюме — править здесь
js/world.js     3D-мир: рельеф, река, лес, базы, босс
js/creeps.js    крипы и вышки
js/tour.js      камера: нырок и экскурсия
js/ui.js        интерфейс, лавка, бой, ачивки
js/audio.js     синтез музыки и звуков
js/main.js      запуск и главный цикл
```

Запуск: открыть `index.html` в браузере (или любой статический сервер).
